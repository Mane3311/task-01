# My Task Manager

This is my first project using Codex. It is a simple task manager built with HTML, CSS, and JavaScript.

## Live Website

[Open My Task Manager](https://mane3311.github.io/task-01/)

## Features

- Add a new task.
- Prevent empty tasks from being added.
- Mark tasks as complete.
- Delete tasks.
- Save tasks in `localStorage`.
- Restore saved tasks when the page is opened again.

## Project Files

- `index.html` contains the page structure.
- `style.css` contains the page design.
- `script.js` contains the application behavior.

## What I Learned

I learned how Codex can create and edit files, how HTML, CSS, and JavaScript work together, and how Git and GitHub can track and publish a project.
